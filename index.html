Retail stock-trading backend

Standard Chartered Bank · 2023–2024

I was the sole backend developer of a Java Spring Boot system for Hong Kong retail stock trading, which handles more than 10,000 trades a day.

The holdings page recomputed cost basis and tax lots for every holding in O(n²) on each refresh. I rewrote it in O(n) with the same results: API latency fell 90% and holdings processing time fell 87%. I also led a rebuild of the notification engine. I traced the business logic through over-abstracted legacy code, then rebuilt it from scratch with the Strategy Pattern and dependency injection, so a new channel needs no core change. I wrote every test; coverage is above 90%.

TravelBuddy

TypeScript · React Native · Expo · private repo

A phone app that wakes you before your stop. Pick a destination and a reminder rule, by distance or by a share of the route estimate, and the app tracks you in the background with GPS. It alerts you as each threshold passes, and again about 200 m before arrival. It works by car, train, bus, on foot, or any mix.

Arrival detection runs entirely on the device, and accounts are optional. iOS uses Apple MapKit through a custom native module. Android uses MapLibre with an OSRM-compatible router. Safety features watch for route deviation and unusual pace, and offer SOS actions. Release builds refuse demo or non-HTTPS map endpoints.
